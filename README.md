# SCDV 2026 — site de campagne de Ruben Binam

Page statique (HTML/CSS/JS) publiée sur https://scdv2026.rubenbinam.com via le déploiement Git d'Hostinger : chaque push sur `main` met le site à jour.

- Aperçu local : `node serve.mjs` puis http://localhost:4321
- Les vidéos, vignettes et l'image de partage viennent du projet `scdv-videos` (`node site-assets.mjs`).
